正弦定理：在任意三角形中，各边与其对角的正弦值之比相等，且等于外接圆直径。
a/sin A = b/sin B = c/sin C = 2R
例题：在 △ABC 中，已知 A=30°, B=45°, a=10，求边 b。
由正弦定理：a/sinA = b/sinB → b = a·sinB/sinA = 10√2
答案：b = 10√2
